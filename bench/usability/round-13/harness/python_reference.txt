/work/report.pmdb is a trace of that run: every call of the program's own functions, in the order the calls started, with its arguments as they were when it started (by parameter name, defaults included; a method's `self` first) and the value it returned or the exception it raised. Query it in Python with the package `recorder`, which is importable:

    import recorder
    from recorder import Q
    t = recorder.load("/work/report.pmdb")        # load once per script (a few seconds)
    print(t.functions())                           # qualified names (e.g. Ledger.post) and call counts
    bad = t.calls("post", raised="ValueError").first()
    t.calls("post", caller=Q("close_month", where=lambda c: c["day"] == 31)).show()
    print(t.calls("post", returned=True).count_by(lambda c: c["txn"]["account"]))

Selecting: `t.calls(*selectors, **conditions)` and `calls.where(...)` return the matching calls (a list, in the order they started). Selectors: a function name ("post" also matches Ledger.post), a compiled regex, a predicate on calls, a call or list of calls, or `Q(*selectors, **conditions)`, combinable with `&`, `|`, `~`. Conditions: `where=pred`; `returned=` True/False, a value or a predicate on the result; `raised=` True/False, a type name or a predicate on the exception; `caller=`, `callee=` (direct), `ancestor=`, `descendant=` (transitive), `before=` (started before a selected call started), `after=` (started after one ended), each taking a selector. Negate a condition, not the selector inside it: `~Q(ancestor="X")` is "not during X".

Selections: `first()`, `last()` (or None), `one()`, `count()`, `values(key)`, `group_by(key)` (dict of selections), `count_by(key)` (Counter), `functions()`, `show(limit=20)`, and `|`, `&`, `-`. A key is a parameter name or a function on calls.

A call `c`: `c["param"]` or `c[i]` (argument by name or position), `c.get("param")`, `c.params`, `c.args`, `c.kwargs`; `c.returned`, `c.raised` (Booleans), `c.result`, `c.exception` (with `type` and `message`; an exception is recorded on every call it passes through); `c.function`, `c.location` (call site), `c.definition`; `c.caller`, `c.callees(...)`, `c.ancestors(...)`, `c.ancestor(...)`, `c.descendants(...)`, `c.path()`, `c.tree(depth=3)`. Each `t.calls` scans the whole trace: in loops, use `c.callees`/`c.descendants`.

Values: None, bools, numbers and strings as themselves; lists and tuples as lists; dicts and named tuples as dicts (`v["field"]`, not `v.field`); other objects as `Opaque` (`.type`, `.unpickle()` rebuilds them if the program's modules are importable). A predicate that raises stops the query with a QueryError naming the call.
